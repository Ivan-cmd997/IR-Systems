# IR Systems — сайт

Статика: HTML + CSS + один небольшой скрипт. Ни фреймворков, ни сборщика, ни
внешних запросов — всё, что грузит страница, лежит в этой папке.

Домен: **ir-systems.ru**. Сайт временно живёт на
`https://ivan-cmd997.github.io/IR-Systems/`, пока домен не подключён к
хостингу — см. «Подключение домена» ниже.

## Запуск

```bash
python -m http.server 4173
```

Открыть <http://localhost:4173>. Деплой — залить папку как есть на Netlify,
Vercel или GitHub Pages, никакой сборки не требуется. `index.html` — стартовая
страница на любом статическом хостинге, менять ничего не нужно.

## Тема

Сайт — бело-чёрно-синий: `css/theme-blue.css` переопределяет всего 7
переменных (`--paper`, `--ink`, `--deep`, `--steel`, `--line`, `--infra`,
`--infra-on-deep`) поверх `css/tokens.css`, который хранит исходную
красно-графитовую палитру из раздела 2 ТЗ («инфракрасный» бренд). Размеры,
отступы, шрифты и вёрстка при этом не меняются ни на пиксель — это одна и та
же система, просто с другим набором цветов сверху. Логотип в шапке нарисован
инлайн-символом с заливкой `var(--logo-ink)`/`var(--logo-tick)`, поэтому он
сам перекрашивается в синий акцент — отдельный файл для этого не понадобился.

Контраст пересчитан для синих цветов: `steel` на белом — 4,9:1, синий акцент
на белом — 8,5:1, светло-синий акцент на тёмном — 6,1:1. Все три с запасом
проходят AA.

Красная палитра в `tokens.css` — исходный брендинг из ТЗ, не задействован
сейчас ни на одной странице, но оставлен как документированный источник
правды на случай, если бренд-гайд понадобится снова.

## Анимация появления

При загрузке страницы блоки не наваливаются все разом:
`IntersectionObserver` в `main.js` добавляет класс `.is-visible` элементам с
классом `.reveal`, когда они входят в область видимости, а внутри
`[data-reveal-group]` они появляются по очереди — каждый следующий на 90мс
позже предыдущего (максимум 360мс задержки, чтобы группа из многих элементов
не тянулась). При `prefers-reduced-motion: reduce` — тот же принцип, что и у
тепловой полосы: анимация отключается, всё показывается сразу.

## Логотип

Четыре SVG нарисованы не «на глаз»: контуры букв I и R взяты прямо из Onest 800
и переведены в кривые, поэтому файлы рендерятся везде и не тянут шрифт за собой.
Построение — по разделу 3 ТЗ: трекинг −0,04em, риска шириной 1/32 от высоты
прописной (ровно 1px на минимальном размере 120px), отступ до `SYSTEMS` равен
ширине буквы I. Сейчас на странице используется только монограмма (инлайн-
символ `#ir-monogram`); отдельные файлы `logo-*.svg`/`monogram-*.svg` были
частью гайдлайна по идентике и удалены вместе с ним.

## Тепловая полоса

Единственная анимация первого экрана, кроме reveal. Сделана чистым CSS
(`@keyframes` + `clip-path`), без JS: если скрипты отключены, полоса всё равно
отрисуется. По умолчанию она нарисована целиком, анимация добавляется только
внутри `@media (prefers-reduced-motion: no-preference)` — то есть при `reduce`
пользователь сразу видит финальное состояние, как и требует ТЗ.

## Два отступления от ТЗ, о которых надо знать

Раздел 2.1 приводит цифры контраста, которые не сходятся с расчётом по WCAG 2.1.
Проверено на живой странице:

| Пара | В ТЗ | На самом деле | Что сделано |
|---|---|---|---|
| `steel` на `paper` | ~4,6:1 | **4,18:1** — не проходит AA | `--steel` затемнён с `#6B7076` до `#656A70` → 4,6:1 |
| `infra-on-deep` на `deep` | «хватает» | **4,12:1** — не проходит AA | осветлён с `#D4392E` до `#DA453A` → 4,6:1 |

Оба значения подобраны как минимально возможные: оттенок и характер цвета не
изменились, но текст от 12px теперь проходит AA. Без этой правки пункты 6 и 11
ТЗ (Lighthouse 100 по доступности, «контрасты из 2.1») противоречат друг другу.

Ещё одна мелочь: в ТЗ написано `hasOffer`, но такого свойства в schema.org
нет. В JSON-LD использовано `makesOffer` с тремя `Offer` — валидный
эквивалент, иначе разметка не прошла бы Rich Results Test.

## Подключение домена (ir-systems.ru → GitHub Pages)

Домен куплен, сайт пока на `ivan-cmd997.github.io/IR-Systems/`. Чтобы он
заработал на `ir-systems.ru`:

1. **DNS у регистратора.** В панели управления доменом (там, где покупали
   `ir-systems.ru`) найти раздел DNS-записей и добавить:
   - четыре **A-записи** для корня домена (`@`) на IP-адреса GitHub Pages:
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - **CNAME-запись** для `www` → `ivan-cmd997.github.io`
2. **Файл CNAME в репозитории.** Создать в корне репозитория файл `CNAME`
   (без расширения) с единственной строкой `ir-systems.ru` и запушить —
   без него GitHub не поймёт, какой домен обслуживать.
3. **Settings → Pages на GitHub.** В репозитории
   `github.com/Ivan-cmd997/IR-Systems` → Settings → Pages → поле
   **Custom domain** → ввести `ir-systems.ru` → Save.
4. **Подождать.** DNS обновляется от нескольких минут до суток. GitHub
   покажет зелёную галочку, когда всё увидит.
5. **Enforce HTTPS.** Как только галочка зелёная, там же появится чекбокс
   «Enforce HTTPS» — включить его, чтобы сайт всегда открывался по https.

После этого `ir-systems.ru` и так уже прописан во всех `canonical`, `og:url` и
JSON-LD на странице — менять в коде ничего не придётся.

## Проверено

На локальном сервере, программно: ошибок в консоли нет, все ресурсы отдают
200, три шрифта грузятся и применяются, горизонтального переполнения нет ни на
360px, ни на десктопе, иерархия заголовков без пропусков (один `h1`, дальше
`h2`/`h3`), у всех картинок есть `alt` и заданы `width`/`height`.

Контраст посчитан по WCAG 2.1 для каждого текстового элемента страницы против
его фактического фона: **0 нарушений**. Все размеры текста — ровно шесть
значений шкалы (12 / 15 / 17 / 22 / 40 / 76 на десктопе), все цвета — ровно
токены из `tokens.css` / `theme-blue.css`.

Логику reveal-анимации подтвердил вручную: правило `.reveal.is-visible
{ opacity: 1 }` побеждает `.reveal` по специфичности CSS (0,2,0 против 0,1,0),
классы расставляются с задержками 0/90/180/270мс внутри каждой группы — но
саму анимацию вживую в этой сессии посмотреть не вышло: браузерная панель в
этой среде держит документ в состоянии `hidden`, а в этом состоянии Chromium
приостанавливает `IntersectionObserver` и рендер-кадры (та же причина, по
которой не получилось снять скриншоты и прогнать Lighthouse). Откройте сайт в
обычном браузере и проверьте анимацию и Lighthouse глазами — это
единственное, что осталось непроверенным вживую.
